Tentang website ini

Belajar Ceria adalah materi interaktif untuk anak SD kelas 1–3 yang dibuat hanya dengan HTML, CSS, dan JavaScript. Website ini bisa dibuka tanpa internet dan tidak mengumpulkan data apa pun. Jumlah bintang hanya disimpan di browser perangkat yang dipakai.

Ikon

Ikon gambar menggunakan Twemoji. Hak cipta grafis © Twitter, Inc. dan kontributor lainnya, dilisensikan di bawah CC BY 4.0.

Font

  • Poppins oleh Indian Type Foundry
  • Montserrat oleh Julieta Ulanovsky dan kontributor

Kedua font berlisensi SIL Open Font License 1.1. Teks lisensinya ada di folder assets/fonts.

Ilustrasi

Maskot Kancil, awan, dan latar perbukitan adalah ilustrasi SVG asli yang dibuat khusus untuk website ini.

Suara

Suara pembaca memakai fitur bawaan browser (Web Speech API), dan efek bunyi dibuat langsung dengan Web Audio API, sehingga tidak ada file suara yang disertakan.
